# 经期助手

微信小程序，用于保存实际经期并提供带适用性说明的日期估计。开发者工具导入项目目录即可运行；无运行时第三方依赖。

## 记录与纠错

- 日历第一次点击选择实际开始日，第二次点击选择实际结束日；同一天点击两次可记录一天经期。两次点击之间保存的是草稿，不会自动生成实际出血日期。
- 结束日未确定时，可“保存为进行中”。进行中事件仅确认开始日，不计算经期时长，也不自动结束。日历上显示从开始日到今天的范围，页面上方显示“第 N 天”。点击这段范围中的任意一天可直接设为结束日；也可以用“今天结束 / 选择结束日”，或在记录编辑中关闭“尚未结束”。持续超过 10 天会提示确认是否已经结束。
- 点击日历中的已有记录或记录列表，可独立核对、编辑、删除。相邻事件不会自动合并；重叠输入需要先编辑已有事件。
- 如果上次与本次之间有漏录，在编辑页标记“有漏录”。原始开始日间隔仍保留，但这个间隔不参与周期平均和预测。补录的记录落在已标记漏录的间隔里时，保存前会询问补录后哪一段仍有漏录，并相应更新两条记录的标记。删除记录时，它的漏录标记会转到下一条记录，因为合并后的间隔仍包含那段漏录。
- 未来日期不能新建为实际记录。真实长时间出血可以确认保存，算法不会为了适配模型改短事实。

## 数据和升级

`utils/store.js` 管理版本 2 的 `cycle_data`：事件数组 `periods`、草稿 `draft`、预测偏好 `preferences` 和首次设置状态。统计值与预计日期全部派生，不重复作为事实保存。

旧版只保存日期列表，无法辨别哪些日期经过实际确认。升级时：

1. 严格检查原数据；格式异常会停止迁移，不写回默认空记录。
2. 将原始数据完整备份到 `cycle_data_backup_v1`，再迁移版本；备份失败则停止。首次备份不覆盖，后续不同的旧版数据另存 `cycle_data_backup_v1_latest`。
3. 日期仅去重和组合连续区间，保留原始日期及区间，全部标为“待核对”。未来旧日期也保留，不能自动删除或缩短。
4. 用户核对实际起止日并保存后，该记录才进入统计。旧版自定义参数保持为手动模式，可“恢复自动预测”而不清空历史。

普通读取、月份导航、前台恢复和跨日刷新不保存数据。业务修改先校验、成功写入后才更新确认状态；保存失败保留原状态及可重试草稿。

“备份并重置”会先保留 `cycle_data_backup_before_reset`，首次备份不覆盖；后续不同内容保留在 `cycle_data_backup_before_reset_latest`。备份失败则不重置。备份与原记录一样，仅在本地保存。

“从本机备份恢复”会列出本地保留的重置前、恢复或导入前以及旧版备份（空备份、无法读取的备份以及与当前数据相同的备份不列出），确认后替换当前数据。替换前会把当前数据另存为 `cycle_data_backup_before_restore`（恢复和导入共用，只保留最近一次），所以恢复和导入本身也可以撤回。旧版备份恢复后同样全部标为“待核对”。记录读取失败时，错误提示里也提供恢复入口。

记录中的纯日期按录入时确认的公历日保留；“今天”取设备当前所在地日期。切换时区或回拨设备日期后，既有记录不会被删除；暂时晚于当地今天的记录会被提示核对，并暂停预测。新建或修改实际日期仍禁止晚于当前今天。

## 导出与导入

本地备份和原记录在同一个地方，删除小程序、系统清理存储或换手机时会一起丢失，所以页面上有“数据备份”卡片：

- **发送备份文件**：把当前全部记录写成 JSON 文件，格式为 `{ app: "menstrual-cycle-miniapp", format: 1, exportedAt, data }`，其中 `data` 就是 `cycle_data`。文件用 `wx.shareFileMessage` 发到聊天，建议发给自己（例如“文件传输助手”）。该接口只能在点击行为中调用，所以点击处理里同步写完文件就直接转发。文件固定写在 `USER_DATA_PATH/cycle-backup.json`，每次覆盖，不会堆积副本。
- **复制备份文本**：把同样的内容放到剪贴板，可以粘贴到自己的备忘录里保存。
- **导入备份**：从聊天中的备份文件（`wx.chooseMessageFile`）或剪贴板导入。支持本小程序导出的文件、直接的 `cycle_data`，以及旧版 `markedDates` 格式（导入后全部标为待核对）。校验方式与恢复相同，格式错误、记录重叠、没有记录或超过 1 MB 的内容一律拒绝，当前记录不会改动。确认弹窗会显示备份中的条数和日期范围；替换前当前数据会另存一份，可以在“从本机备份恢复”中找回。首次打开的设置弹窗里也有“从备份导入”，换手机后可以直接导入。

**发布前需要在后台配置**：`wx.chooseMessageFile`（收集你选中的文件）和 `wx.setClipboardData` / `wx.getClipboardData`（读取你的剪切板）属于隐私接口，需要在「小程序管理后台 → 设置 → 服务内容声明 → 用户隐私保护指引」中声明用途，补充的声明约 5 分钟后生效。未声明时这些接口会直接报错（errno 112），页面会弹出“功能未开通”。用户第一次使用时，微信会自动弹出官方隐私授权弹窗；用户拒绝（errno 103/104）时，页面提示需要先同意。`wx.shareFileMessage` 和文件系统接口不在隐私接口列表中。参考：[用户隐私保护指引内容介绍](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/miniprogram-intro.html)、[隐私协议开发指南](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/PrivacyAuthorize.html)。

导出的文件包含全部经期记录，属于敏感个人信息。文件离开小程序后由用户自己保管，小程序本身仍不上传任何数据。

## 预测规则和限制

- 经期长度包含开始日和结束日，仅计算已明确结束的事件；周期平均使用实际相邻开始日间隔，不将默认 28/5 天伪装成实测平均。统计卡与预测使用同一组样本：最近 12 个有效间隔的平均值，以及最近 12 次已结束经期天数的中位数。用中位数是为了避免单次异常长的出血拉长之后的预计经期。
- 自动模式使用最近最多 12 个未标记漏录的实际间隔，不静默过滤长周期。两个确认开始日之间如果还有待核对的旧记录，这个间隔同样不参与统计；最近确认开始日之后还有待核对记录时暂停预测，先提示核对。至少 3 个间隔、观察范围在 18–45 天内、最大最小差不超过 7 天时才开启远期候选及易孕窗口。以上为软件模型的适用性门槛，不是医学诊断或“正常周期”的定义。
- 样本不足提供明确标注的粗略日期参考；明显波动提供观察范围，不输出自动模式的精确日期或易孕窗口。过长经期或参数组合不适用于固定周期时停止推算，保留真实统计。
- 初次参数是自动模式低样本参考，后续记录会取代它。预测设置显示当前实际使用的天数，调整从这个值开始并显式切换手动模式，可随时恢复自动。
- 从最近确认开始日计算的首次预计日期固定保留，区分尚未到、今天应到和逾期未确认，不自动假定漏录周期已经发生。逾期停止后续周期与易孕窗口外推。
- 排卵窗口按下次经期前约 10–16 天估计，潜在易孕窗口扩展到最早估计排卵日之前 5 天。下一个周期使用观察到的最短到最长间隔，第二个周期把这个范围按 √2 扩展；更远的周期不再推算易孕窗口，因为窗口会互相重叠并覆盖预计经期。以上仅为数学外推，不是经过校准的概率区间。统计卡显示尚未结束的最近一个窗口；日历上预计经期优先显示，不叠加排卵或易孕标记。没有足够适用记录时不显示易孕窗口。
- 日期估计不能确认实际排卵，窗口之外不代表安全期，不能用于避孕判断。参考：[NHS 周期与生育](https://www.nhs.uk/conditions/periods/fertility-in-the-menstrual-cycle/)、[易孕窗口前瞻性研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC27529/)。

纯日期运算通过严格校验的 UTC 日序号完成，避免设备时区及历史整日跳变改变记录日期。前台在午夜后刷新派生显示，最长每 30 秒检查时区/日期变化；返回前台立即刷新，后台和卸载时清理定时器。

## 回归验证

安装 Node.js（本次验证使用 24.15.0），在项目目录运行：

```powershell
npm test
```

或直接 `node --test`。测试使用内存存储和模拟页面（`tests/helpers.cjs`），不修改真实微信记录。`tests/business.test.cjs` 覆盖审计的全部 15 项问题，以及旧版迁移、草稿恢复、独立编辑、进行中事件、重置备份和时间回拨，包含上海、纽约、柏林、阿皮亚四个时区的子进程日期验证。`tests/cycle-logic.test.cjs` 覆盖进行中经期的结束流程、易孕窗口范围、统计口径、漏录标记和备份恢复。`tests/export-import.test.cjs` 覆盖导出文件与剪贴板文本、跨设备导入、首次设置时导入、异常内容拒绝、取消操作和隐私接口报错。

微信打包配置排除测试目录和 Node 测试说明文件。开发者工具/真机仍需验证选择器、弹窗、视图样式和本地存储的原生交互，以及文件转发、选择聊天文件、剪贴板和隐私授权弹窗的实际表现。
